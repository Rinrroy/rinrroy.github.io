# 02

Projects / 项目

kernel_oneplus_sm8250 C
Just another CLO based kernel for OnePlus SM8250 devices. 深度优化内核，支持 KernelSU 集成。
★ 核心项目 📅 2023 🔧 维护中
KernelSU_Action Shell
A action for build KernelSU into your kernel. 使用 GitHub Action 自动编译集成 KernelSU 的内核。
🤖 自动化构建 📅 2024
Action_OnePlus_MKSU_SUSFS Action
使用 Github Action 自动编译一加 SukiSU 内核。一键自动化安全内核编译。
⚡ 一键编译 📅 2025
xiaomi_pad_system_patch Module
小米平板系统优化 Magisk 模块，提升平板使用体验与功能增强。
📱 平板优化 📅 2026
